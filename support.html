Restore Full Access

  1. Open SettingsChoose the Settings tab in FinCalc.
  2. Choose Full AccessTap Restore purchase.
  3. Use the same Apple AccountStoreKit can restore a purchase only for the Apple Account that made it.

Purchase billing and refunds are handled by Apple. If restore does not finish, check your network connection, confirm the account, and try again after the App Store is available.

Change language

In FinCalc, open Settings → Language and choose English, Deutsch, or Français. The selected language changes labels and formatting while keeping a saved calculation's canonical values intact.

The product site has the same language choices in its header. Use the language you prefer when writing a support request.

Export a calculation

From a saved record or scenario, choose the export action and select text or CSV. The export includes the inputs, selected conventions, and result so another person can reproduce the calculation.

Exports are explicit user actions. Review the file before sharing because it may contain the financial values you entered.

Frequently asked questions

FinCalc is a general financial mathematics workspace. It does not provide a regulated loan quote or country-specific advice.

What does FinCalc calculate?

Regular payments, payment schedules, equal-period cash flows such as NPV, IRR, and MIRR, and explicit rate conversions. Results use the values and mathematical conventions you enter.

Why does a result differ from another calculator?

Check the timing, payment frequency, rate convention, sign of each cash flow, and rounding setting. FinCalc keeps these assumptions visible so you can compare them. A support request should include those settings and the smallest example that reproduces the difference.

Where are my calculations stored?

Core calculations and history are stored locally in the app's Application Support data. FinCalc has no account, no default cloud sync, and no advertising. Export and sharing occur only when you choose those actions. You can delete saved records from the app's history or workspace controls.

Does FinCalc need an internet connection?

The calculation and history features are designed to work offline. An internet connection may be needed for App Store purchase or restore verification and for actions that leave the device, such as sharing an export.

What information should I include in a bug report?

Include the app version, device model, iOS or iPadOS version, app language, calculator module, input values using fictional data, expected result, actual result, and a screenshot if it does not reveal private information. Never post bank-account numbers, names, addresses, or other sensitive data.

Your data stays in your control

FinCalc stores calculation history locally by default. There is no FinCalc account, cloud sync, advertising, or financial-input analytics. A CSV or text export is a file you choose to create and share.
